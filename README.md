# Gym Log（iPhone向けローカル記録PWA）

## 機能
- 今日の固定メニュー（10種）
- 各セットの完了チェック
- 重量・回数の記録
- 前回記録の表示
- セット完了時の自動インターバルタイマー
- ランニングの時間・距離記録
- 過去履歴
- JSONバックアップ
- データはブラウザのローカルストレージに保存
- 音・バイブ通知なし

## 初期インターバル
- 主要種目: 120秒
- 補助種目: 90秒
設定画面から変更できます。

## iPhoneでホーム画面アプリとして使う
PWAとしてホーム画面へ追加するには、通常 `https://` で配信する必要があります。
GitHub Pages / Cloudflare Pages / Netlify などの静的ホスティングに、このフォルダの中身をそのまま置いてください。
データ自体はサーバーへ送信せず、iPhone内のブラウザストレージに保存されます。

Safariで公開URLを開き、
共有 → 「ホーム画面に追加」
で利用できます。

## 注意
Safariの「履歴とWebサイトデータ」を削除すると記録も消える可能性があります。
定期的に「設定 → JSONを書き出す」でバックアップしてください。
